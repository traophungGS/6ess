# RULES

All rules are as in Chess except:

1. There is no pawn double-step move, nor is there the en passant capture.
2. Pawns may only be promoted to already taken pieces, if one doesn't exist no promotion occurs.
3. Castling is only on the queens side, but the notation used is that of a king's side castle.
4. Pawn promotion follows normal Chess rules, but the replacement piece must be a previously captured piece of the same colour. If one is available, promotion is mandatory and immediate. Otherwise, the pawn remains on the board but cannot move, though it can still be captured normally.
